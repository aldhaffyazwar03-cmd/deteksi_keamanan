# deteksi_keamanan
Sistem ini merupakan aplikasi deteksi dan pengenalan wajah berbasis komputer visi (Computer Vision) dan Pembelajaran Mesin (Machine Learning) yang diintegrasikan ke dalam sebuah aplikasi web berbasis Flask. Secara umum, sistem ini dibagi menjadi 3 tahap utama: pengumpulan data, pelatihan model, dan deteksi real-time.
